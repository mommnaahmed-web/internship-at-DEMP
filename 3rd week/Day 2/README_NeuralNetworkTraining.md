## 📓 Notebook — `neural_network_training_notebook.ipynb`

An end-to-end walkthrough of how neural networks learn, built around the
**Fashion MNIST** dataset.

### Topics covered

1. **The Training Loop** — the repeating 5-step cycle: forward pass → error → cost → parameter update → repeat
2. **Loss Functions** — MAE, MSE, RMSE, Huber, Binary Cross-Entropy, Categorical Cross-Entropy, Sparse Categorical Cross-Entropy
   - *Task 1*: Implement loss functions from scratch with NumPy (cross-checked against scikit-learn)
   - *Task 2*: Visualize regression and classification losses (filled-area style plots)
3. **Gradient Descent** — the θ ← θ − η·∇J update rule
   - *Task 3*: Implement gradient descent on a simple linear regression problem
4. **Backpropagation** — chain rule and gradient computation
5. **Optimizers** — SGD, Momentum, RMSProp, Adam (comparison table)
   - *Task 4*: Train an ANN with TensorFlow/Keras on **Fashion MNIST**, comparing **RMSProp vs. Adam**
6. **Hyperparameter Tuning** — learning rate, batch size, epochs
   - *Task 5*: Hyperparameter experiments (Adam optimizer) with results logged to a comparison table
7. **Model Evaluation Visuals**
   - *Task 6*: Loss/accuracy curves, confusion matrix, ROC curve, precision–recall curve (one-vs-rest view for the "Sneaker" class, since this is a multi-class problem)
8. **Results & Discussion**
9. **Literature Review** — summary and synthesis of three published papers comparing optimizers
10. **Wrap-Up & References**

### Requirements

```bash
pip install tensorflow scikit-learn pandas matplotlib
```

(The first cell of the notebook installs these automatically.)

### How to run

```bash
jupyter notebook neural_network_training_notebook.ipynb
```

Plots and CSV comparison tables generated by the tasks are saved to an
`outputs/` folder created alongside the notebook.

> **Dataset used:** Keras's built-in **Fashion MNIST** dataset
> (`tf.keras.datasets.fashion_mnist`) — 10-class grayscale clothing images,
> downloaded automatically on first run, no manual download needed.

## 🖥️ Presentation — `Neuralnetwork_training.pptx`

A 20-slide lecture deck that mirrors the notebook's structure, intended for
in-class delivery.

### Slide flow

- **Title & Roadmap** — 8 learning outcomes for the session
- **60-Second Recap** — layers, weights/biases/activations, forward propagation
- **The Training Loop** — five steps, plus a diagram view
- **Loss Functions** — regression losses, classification losses, and a task-to-loss comparison table
- **Gradient Descent** — the core idea, cost surface, and Batch/SGD/Mini-Batch variants with a convergence chart
- **Backpropagation** — error propagation and a computational-graph view
- **Optimizers** — SGD, Momentum, RMSProp, Adam comparison
- **Terminology Check** — Epoch vs. Batch vs. Iteration, with a worked example
- **Evaluating Training** — learning curves, accuracy curves, early stopping
- **Common Problems** — vanishing/exploding gradients, poor initialization — with fixes
- **Best Practices** — LR scheduling, batch size selection, epoch selection, checkpointing
- **Wrap-Up**

### How to use

Open directly in PowerPoint, Keynote, or Google Slides — no additional
software required.

## 🎯 Learning Outcomes

By the end of this material, learners will be able to:

- Understand how a network improves with each training pass
- Work through the math that drives training
- Compare regression and classification loss functions
- Build gradient descent from scratch
- Trace gradients through backpropagation
- Compare optimizer algorithms (SGD, Momentum, RMSProp, Adam)
- Read learning curves to catch overfitting
- Train a real ANN on Fashion MNIST with Keras
