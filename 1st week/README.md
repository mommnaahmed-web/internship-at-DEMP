## Tasks

### 1. Supervised Learning Models

Studied core supervised learning algorithms used for classification and regression.

- Covered K-Nearest Neighbors, Naive Bayes, Random Forest, and Logistic Regression
- Explained how each model works and where it's best applied
- Compared the models conceptually before applying them to real datasets

### 2. Supervised Machine Learning in Finance

Applied supervised learning models to finance-domain prediction problems.

- Built a stock market regression model using Linear Regression on price/volume features
- Predicted loan approval amounts using regression on applicant data
- Built classification models for loan default and credit card fraud detection
- Interpreted results using R², feature importance, and metrics like Recall for imbalanced fraud/default data

### 3. Optimization Techniques in ML

Studied how models are trained by minimizing a loss function using gradient-based optimization.

- Explained the mathematics of Gradient Descent and the role of the learning rate
- Covered Batch, Stochastic, and Mini-batch Gradient Descent
- Introduced Momentum and the Adam optimizer, and compared convergence behavior

### 4. Optimization Techniques – Implementation

Implemented gradient-based optimizers from scratch and compared their convergence.

- Implemented loss and gradient functions on generated dummy data
- Built Batch Gradient Descent, Stochastic Gradient Descent, and Mini-batch Gradient Descent from scratch
- Implemented the Adam optimizer and plotted a convergence comparison across all techniques

## Learning Outcomes

- Understood the working principles of KNN, Naive Bayes, Random Forest, and Logistic Regression
- Applied supervised learning models to real-world finance problems: stock prediction, loan approval, default, and fraud detection
- Evaluated models using appropriate metrics for regression and imbalanced classification
- Understood the mathematics behind Gradient Descent and the effect of the learning rate
- Implemented Batch, Stochastic, and Mini-batch Gradient Descent, plus Momentum and Adam, from scratch
